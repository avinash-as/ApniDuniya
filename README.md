# 🎬 ApniDuniya

A full-stack movie ticket booking platform that allows users to discover movies, explore show timings, book seats, and manage their bookings through a modern and responsive interface.

## 🚀 Features

- 🔐 User Authentication & Authorization
- 🎥 Browse Movies
- 📅 View Show Timings
- 🎫 Book Movie Tickets
- 💺 Seat Selection
- 👤 User Profile & Booking History
- 📱 Responsive Design
- ⚡ Fast and Interactive UI
- 🔍 Search Movies
- ❤️ Favorite Movies (Optional)

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- Framer Motion

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Bcrypt.js

### Other Tools
- Git & GitHub
- Cloudinary (Media Storage)
- Postman (API Testing)
